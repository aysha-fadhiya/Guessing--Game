# Number Guessing Game 🧠🎯

A simple number guessing game I built using Python.

## What it does
- Picks a random number between 1 and 100
- You try to guess it
- It tells you if you're going too high or too low
- Keeps track of how many attempts it took you

## How to run
Make sure Python is installed on your system then just run:
python game.py

## What I learned
Built this while learning Python basics — loops, conditions and the random module.
